# AR Follow-Up Checklist

Use this checklist for each unpaid or aging claim.

## 1. Review the claim
- [ ] Confirm patient and insurance details are correct
- [ ] Confirm the date of service and billed amount
- [ ] Check the claim status in the billing system or payer portal

## 2. Identify the problem
- [ ] Claim not received by the payer
- [ ] Claim pending or in process
- [ ] Claim denied (note the denial code and reason)
- [ ] Underpaid or partially paid

## 3. Take action
- [ ] Resubmit the claim if it was not received
- [ ] Send a corrected claim if there was a data error
- [ ] Call the payer if the status is unclear
- [ ] Start an appeal if the denial is incorrect
- [ ] Request missing documents or authorization

## 4. Document everything
- [ ] Date and time of the follow-up
- [ ] Payer representative name and call reference number
- [ ] Action taken and the outcome
- [ ] Next follow-up date

## 5. Close the loop
- [ ] Post the payment (ERA/EOB) when received
- [ ] Transfer the remaining balance to the patient if applicable
- [ ] Mark the claim as resolved
