# Medical Billing Templates

Free, practical templates and checklists for US medical billing and Revenue Cycle Management (RCM).

> **Privacy notice:** All examples in this repository use fake sample data only. No real patient information (PHI) is stored here. Do not upload real patient data to this repository.
